# angi — Hôm nay ăn gì? 🍜

Máy chọn món trưa có thái độ: chê càng nhiều, nó càng mặn.

**Live:** https://angi.wakeuplate.io.vn/

AI lunch decider with escalating sass, powered by a self-hosted LLM (Ollama +
qwen2.5:7b). Server-side dish picking, LLM one-liners with a canned-humor floor,
real Hanoi/Saigon weather integration. FastAPI + vanilla JS, one Docker container.

See [CLAUDE.md](CLAUDE.md) for build/run commands, architecture, and ops notes.
